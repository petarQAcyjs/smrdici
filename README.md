# 👨‍👩‍👧‍👦 Smrdici - Породична Апликација

Smrdici је свеобухватна породична апликација дизајнирана да помогне породицама да организују свој живот кроз заједничке функционалности као што су буџет, календар и листе задатака.

</p>

## ✨ Функционалности

- 🔐 **Аутентикација**: Пријава и регистрација корисника путем email/password и Google налога
- 💰 **Породични буџет**: Праћење прихода и расхода целе породице
- 📅 **Заједнички календар**: Координација породичних догађаја и обавеза
- 📝 **Породичне листе**: Креирање и дељење листа за куповину, задатке и белешке

## 🛠️ Технологије

- **Kotlin**: Модеран програмски језик за Android развој
- **Jetpack Compose**: Декларативни UI toolkit за изградњу нативних Android апликација
- **Firebase Authentication**: Безбедна аутентикација корисника
- **Firebase Realtime Database**: Чување и синхронизација података у реалном времену
- **MVVM архитектура**: Чист и одржив дизајн апликације

## 🚀 Почетак рада

### Предуслови

- Android Studio Arctic Fox (2021.3.1) или новији
- JDK 11 или новији
- Android SDK 34 или новији

### Инсталација

1. Клонирајте репозиторијум:
   ```bash
   git clone https://github.com/YOUR_USERNAME/Smrdici.git
   ```

2. Отворите пројекат у Android Studio-у

3. Синхронизујте Gradle фајлове

4. Покрените апликацију на емулатору или физичком уређају

## 📱 Коришћење

### Аутентикација
- Корисници се могу регистровати користећи email и лозинку
- Алтернативно, могу се пријавити користећи свој Google налог
- Након успешне пријаве, корисници се преусмеравају на почетни екран

### Навигација
- Из почетног екрана, корисници могу приступити различитим функционалностима:
  - Буџет
  - Календар
  - Листе
