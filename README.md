# Смрдици - Породична Организациона Апликација

## О апликацији

Смрдици је породична организациона апликација дизајнирана да помогне породицама да организују своје свакодневне активности, догађаје и обавезе. Апликација је развијена за Андроид платформу користећи Kotlin и Jetpack Compose.

## Функционалности

### Почетни екран
- Преглед данашњих активности
- Брзи приступ главним функцијама апликације (Листе, Календар, Буџет)
- Филтрирање прошлих догађаја и приказ само активних и будућих догађаја

### Календар
- Месечни преглед календара
- Додавање, уређивање и брисање догађаја
- Детаљни преглед догађаја за изабрани датум
- Подршка за целодневне догађаје
- Избор боје за догађаје
- Подешавање времена почетка и завршетка догађаја

### Листе
- Креирање различитих типова листа (куповина, задаци, итд.)
- Додавање, уређивање и брисање ставки у листама
- Означавање завршених ставки

### Буџет (у развоју)
- Праћење породичних трошкова
- Категоризација трошкова
- Месечни буџетски извештаји

## Техничке карактеристике

- **Архитектура**: MVVM (Model-View-ViewModel)
- **UI**: Jetpack Compose
- **База података**: Firebase Firestore
- **Аутентификација**: Firebase Authentication
- **Језик**: Kotlin
- **Минимална верзија Андроида**: API 24 (Android 7.0 Nougat)

## Инсталација

1. Клонирајте репозиторијум
2. Отворите пројекат у Android Studio
3. Синхронизујте Gradle фајлове
4. Покрените апликацију на емулатору или физичком уређају

## Будући развој

- Имплементација буџетског модула
- Додавање подршке за понављајуће догађаје у календару
- Дељење листа и догађаја са члановима породице
- Обавештења и подсетници за догађаје
- Синхронизација са Google календаром и другим календарским апликацијама
